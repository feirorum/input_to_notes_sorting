# Classification examples

Saved corrections that teach the sorter. Each user correction appends a block
here and inserts a row the example-similarity matcher uses for future routing.

## Example: child size notes
- **Input:** Flora's feet are now size 34.
- **Correct destination:** notes/family/flora.md
- **Category:** family
- **Notes:** Short family facts about a specific child go to that child's family
  record, not to shopping.
