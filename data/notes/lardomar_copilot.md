## Användningsområden

GitHub Copilot är användbart för att snabbt generera kodmallar och boilerplate-kod. Särskilt effektivt när man skriver enhetstester.

## Tips och tricks

- Använd tydliga kommentarer för att styra Copilot
- Fungerar bra med pytest för att generera testfall
- Kan föreslå hela funktioner baserat på funktionsnamn
- Bra på att identifiera mönster i befintlig kod

## Begränsningar

- Behöver ibland granskning för säkerhet och prestanda
- Kan generera föråldrad kod om bibliotek har uppdaterats
- Fungerar bäst med vanliga programmeringsspråk

## Exempel

Vid testskript med pytest kan Copilot automatiskt föreslå fixtures och assert-satser baserat på funktionens signatur.
